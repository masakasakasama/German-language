# ゼロからわかるドイツ語

日本語話者が、旅行フレーズの形を自分で説明できるようになる基礎コース。ホームとレッスン画面から開ける。全14課、各課に説明2節・分解した例文2つ・練習3問を収録。1課10〜15分を目安にする。

| 課 | 学ぶしくみ |
|---|---|
| 01 | ei/ie、ウムラウト、名詞の大文字 |
| 02 | 主語・動詞・文のかたまり、動詞第2位 |
| 03 | 人称と規則動詞の活用 |
| 04 | sein/haben の現在形、状態と所有 |
| 05 | 文法上の性、定冠詞・不定冠詞・複数 |
| 06 | 主格と対格、男性冠詞の変化 |
| 07 | 与格、受け手、動詞や前置詞が要求する格 |
| 08 | 動詞を先頭にする疑問文、疑問詞の文 |
| 09 | nicht と kein、否定する対象 |
| 10 | 話法の助動詞＋文末の不定詞 |
| 11 | 分離動詞、助動詞がある場合との比較 |
| 12 | 前置詞の格支配、場所と行き先、im/ins |
| 13 | 完了形、haben/sein と過去分詞 |
| 14 | weil の従属文、動詞の末尾配置 |

説明はルールを先に提示し、日本語との違いを示して、例文を役割別に分解する。格は日本語の助詞の置き換えとして教えず、動詞・前置詞による格支配と役割を説明する。文法上の性を生物的な性別と混同しない。二格支配前置詞は単なる運動の有無ではなく場所と方向を区別する。助動詞、分離動詞、完了形は文の枠という共通点でつなげる。

各課は説明を読んでから、3枚の理解度自己評価と3問の選択/入力練習を交互に行う。練習の不正解は理由を読んで再挑戦し、正解するまで課のその練習ステップを完了扱いにしない。基礎の入力問題は名詞の大文字も学ぶため大文字・小文字を区別する。誤答、再挑戦、自己評価は既存の記録・SRSに保存する。42枚の基礎カードは復習・苦手カード・コレクション・JSONバックアップにも含める。既存データベースのスキーマを変えず、旅行教材のIDも維持する。

自由に課を読み返せる。上からの順番を推奨するが、課をロックしない。完了は練習した印で、定着や資格の認定を意味しない。完全なA1試験対策コースではなく、初級文法を理解する土台とする。

## 図解（0.1.3）

全14課に2図ずつ、28図を追加。単語・語句を色付きの箱と矢印で並べて、平叙文と疑問文、主格と対格、現在形と完了形などを上下で比較する。図中の「動詞」「主語」「与格」などを選ぶと、その役割の箱を強調できる。役割は教材として明示し、単語の綴りから自動推測しない。色だけに頼らず日本語の役割ラベルも付ける。名詞・活用語尾・接続語を主語や対格と混同しないよう別の分類を持つ。

28例文の分解も、1行の文章から意味ごとの箱に変更。小さな画面では箱を折り返し、長い語句は箱内でも折り返す。文は左から右、次の行へと読む。説明・図・例文・練習を同じ課の中でつなげ、課のID・問題・学習データは維持する。

## 更新の動作

0.1.1はマイページで手動確認。基礎コース追加版では起動時の自動確認を初期値ONにし、設定でOFFにできる。新しい版だけを案内し、バックグラウンドで無断インストールしない。利用者がダウンロードを選び、サイズ・SHA-256・パッケージ・版数・既存署名を検証した後、Androidのインストーラで利用者が確認する。ネット接続がなくても教材と学習は使える。

0.1.1のAndroid 9〜12では署名情報の取得フラグに不具合があるため、この端末では新しいAPKをブラウザからダウンロードして更新する。追加版でフラグを修正。初回と同じ署名鍵・application IDを使い、アンインストールを必要としない。

## 検証

教材の全設問で、正解だけを判定が受理し、誤答選択肢を拒否することをJVMテストする。カードID・レッスン参照の一意性、名詞の大文字判定も確認する。テスト・lint・署名付きreleaseビルド後、公開APKを取り直し、旧版と署名が一致することと更新フィードの版数・サイズ・ハッシュを確認する。実機操作・OSインストーラの確認は別途必要。

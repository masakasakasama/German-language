# 部位ごとのキャラクターアニメーション（0.1.8）

採用された背景透過画像を48×48の接続メッシュで描画する2Dパペットです。3Dモデルを新しく作ったものではありません。画像全体の回転・浮遊・拡大縮小は行いません。

- 3.6秒周期で胸が小さく膨らみ、コートの裾が追従します。
- 首を支点に頭がわずかに動き、耳先は位相をずらして追従します。
- 肩→肘→手首の局所変形で挨拶します。開始と終了は滑らかに減速し、通常は9秒周期、タップでも再生します。
- 「足踏み」は4秒間、股関節・膝・足首を左右逆位相で動かします。元の正面ポーズを変形させる足踏み表現で、横向きに歩いて移動する3D歩行ではありません。
- 「ジャンプ」は0.35秒の準備、0.6秒の放物線状の跳躍、0.4秒の着地吸収です。膝・胴体の圧縮と耳の追従を加え、かばんも一緒に持ち上がります。頭上に余白を確保します。
- 接続メッシュと滑らかな部位の重みを使用し、腕と袖を別画像として分離しません。待機中・手振り中は足とスーツケースを固定します。
- 全画面の `CompanionCharacter` と `TravelBunny` に適用します。ランチャーアイコンは静止画です。
- バックグラウンド・停止中はフレーム更新を止め、最後の姿勢を保持します。端末のアニメーション無効設定時は自動再生せず、明示的な再生操作を受け付けます。

`CompanionMotion.kt` が動作データとメッシュ計算、`AnimatedTravelCompanion.kt` がAndroid Canvas.drawBitmapMeshによる描画を担当します。外部サービス、動画ダウンロード、追加権限は不要です。

`CompanionMotionTest` は再生条件、手振りの開始・終了、足の固定、胸・手の変位、355フレーム（待機・足踏み・ジャンプ）の全三角形の向き（折り返しなし）を検証します。同じKotlin計算から `app/build/motion-preview.json` を出力します。プレビューはその頂点データをブラウザのWebGLで描画したものです。Android実機の録画ではなく、端末上のフレーム速度・描画品質は未検証です。

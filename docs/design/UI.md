# 画面・ビジュアル仕様

## 世界観と部品

参考画像は `reference/reisedeutsch.jpg`。水彩の旅行絵本の雰囲気を再現する。空と川は青、紙は温かい白、重要な操作は赤、進捗は緑。マスコットは白いうさぎに赤いベレー帽、紺の上着、赤い旅行鞄。喜ぶ/案内/聞く/応援の4表情。失敗時は困った顔で責めず、「もう一度、ゆっくり。」と案内する。

景観やイラストは装飾。文字は白/クリームの不透明な面に置き、背景の描き込みで読みづらくしない。ドイツ語は標準的なSans、日本語はNoto Sans JPまたはシステムSans、ロゴだけSerifで `Reise` と `Deutsch` を色分けする。フォントを使う場合は同梱とライセンス記録を必須とする。

共通 `Design_system` のsemantic/componentトークンを基盤とし、ReiseDeutsch専用aliasを `tokens/reise-tokens.json`（実装時作成）に集約する。画面にHEX/dp/spを直接散在させない。共通repoを変更せず、共通値を参照し、ブランド専用値のみローカルaliasへ追加する。

淡い赤・黄・緑は面と装飾に使い、本文色には使わない。上記カラーは仕様値であり、実装時の文字サイズ別コントラスト検証で4.5:1（通常文字）/3:1（大きい文字・UI）を満たすこと。

spacingは共通4/8/12/16/24/32/48、カード角丸24、小部品12、ボタンpill。本文16sp/行24sp、見出し22/28、補助13/18、ドイツ語フレーズ22/30をalias定義。主要CTAは高さ56dp以上、評価ボタン・アイコンのタッチ領域48dp以上。共通motion120/220/360ms、通常の切替220ms。音声録音中以外の無限アニメーションは置かない。

## レイアウト規則

基準幅412dp、画面左右16dp、カード内16dp、部品間12〜16dp。ステータスバー/ジェスチャー領域にはinsetsを適用する。600dp未満は単列＋下部タブ、600dp以上は最大840dpの中央コンテンツ＋navigation rail。ホームの場面カードは2列、幅360dp未満か大きい文字では1列。画像のスマホ枠はアプリ画面に含めない。

重要テキストは省略しない。翻訳・説明は折り返し。横向き会話は履歴と入力を2領域にできるが、端末の最小高さを超える固定高さを置かない。地図も一覧モードを備え、ピンチ操作に依存させない。

## ホーム S01

上部は空と街の短いヒーロー。GreetingCardの左に `Guten Morgen!` 等、右に案内うさぎ。時間別の文言は05–11時/11–18時/18–05時。初回は数値0、既存データがあるように見せない。

ミッションはターゲットアイコン＋「今日のミッション」＋「カフェの3フレーズを練習しよう」＋進捗0/3＋矢印。達成後はチェックと「できた！」、次回は明日。復習カードは未達の場合も独立して押せる。未完了セッションがあれば「続きから」を優先CTAにする。

実績3列: 連続日数、総XP、教材目安A1。下にカフェ/駅・電車/ホテル/観光・街歩きの画像カード。進捗は完了レッスン数/対象レッスン数を表示し、画像の3/5などは固定値にしない。

## 地図 S02

画像のドイツ地形・ランドマークを踏襲。旅程順は **Hamburg → Berlin → Köln → Frankfurt → München**。地図上の位置は実際の方角に近づけ、学習順に地理を歪めない。点線のルートが交差しても問題ない。地理的に最短の旅行経路を意味しない旨はヘルプに記載。

都市ノードは48dp以上、地図座標は正規化0..1で保持。正規化位置目安: Hamburg(0.50,0.16)、Berlin(0.79,0.30)、Köln(0.18,0.46)、Frankfurt(0.36,0.64)、München(0.70,0.83)。画像用ビューポート360×560。小画面は縦スクロール。現在地は未完了都市。完了都市はチェック、今の都市は赤、以降は輪郭＋「次の街」。将来都市はプレビューできるが、完了の順序は前都市の完了後。全都市到達後も学習・復習は継続できる。

地図の視覚表現だけで状態を伝えない。都市名、4レッスン中x完了、現在/完了/未到達のアクセシブルラベルを付ける。一覧切替時は同じ状態と遷移。

## 学習 S05

紹介: フレーズ→再生→「答えを見る」→日本語訳・要点・例文→「わからない/少しわかる/わかる」。次回予定は選択前に各ボタンの下へ表示。選択すると保存し「次へ」を有効化。押し直しは未遷移の同一イベントを差し替え、2回の学習として扱わない。

客観問題: 回答→判定＋解説→「次へ」。自己評価は追加で必須にしない。誤答カードを再練習キューに入れる。結果を見てすぐ自動送りしない。音声問題では訳を回答後に表示。

途中の閉じるは「学習を中断しますか？ 保存済みの回答は残ります。」＋「続ける/中断」。評価前のカードは未回答として再開。バックグラウンド移行だけでは中断ダイアログを出さない。

## 会話 S09

画像中央のカフェ画面を基準に、相手の白い吹き出し、自分の青い吹き出し、右側のうさぎを配置。各フレーズに音声ボタン。日本語訳は初期表示、設定で隠せる。会話は固定分岐で、AI生成会話にはしない。

マイクボタンは赤の円形（72dp、タッチ領域含む）。状態は待機→権限確認→録音中→認識中→結果確認→再練習/次へ。録音は最大15秒、再タップで停止。認識テキストを本人が修正/確定してから判定する。下部に必ず「文字で答える」。認識が一致した場合も「発音100点」とせず、「フレーズを確認できました」と表示する。

下部の関連表現は本文と音声を持ち、タップでS11へ。録音中の画面離脱で録音を停止し、音声ファイルを残さない。

## 状態・アクセシビリティ

| 条件 | 表示/動作 |
|---|---|
| 初回・復習0件 | うさぎ＋「今日の復習はありません」、新しいレッスンへ |
| フィルタ該当0件 | 条件を表示、「フィルタを解除」 |
| 教材読込失敗 | 再試行、設定→診断。空のコースを成功扱いしない |
| 音声なし | 再生アイコン無効＋「ドイツ語音声が未設定」、テキスト学習は続ける |
| マイク拒否/非対応/オフライン認識不可 | 理由と文字回答への切替、再要求の連発を避ける |
| 学習保存失敗 | 回答内容を保持、再試行、次への操作は無効 |
| 更新なし/通信失敗 | 区別して表示。「最新版」と通信失敗を混同しない |
| 動きを減らす設定 | 移動/紙吹雪停止、静的チェックと実績で完了を示す |

TalkBack順序は見出し→説明→操作、装飾は読み上げ対象外。音声ボタンは「フレーズをドイツ語で再生」と対象を明示。色とアイコンだけで正誤/都市状態/評価を示さない。200%文字サイズ、320dp幅で主要操作が切れない。実績の画像内文字は使用せずUIテキストで表示する。
